## ✦ About Studio91

**Studio91** is an independent digital product studio based in **Jaipur, Rajasthan, India** (Est. 2024).

> *Studio91 empowers users by replacing complex visual interfaces with human-centered AI, turning natural speech into effortless device automation.*

We craft calm, intentional software inspired by modern digital wellness, simplicity, and purposeful technology. We believe software should respect human attention, stripping away clutter until only what matters remains.

### Brand Values & Aesthetics
- **Core Values:** Minimalism · Human-Centeredness · Intentionality · Mindfulness
- **Visual Aesthetics:** Editorial Serenity · Calm Digitalism · Humanistic Minimalism · Spacious Restraint · Intentional Warmth
- **Tone of Voice:** Calm · Intentional · Thoughtful · Minimal

### Core Principles

1. **Humanistic Minimalism:** Replacing complex visual interfaces with human-centered AI. We strip away friction until natural speech translates into effortless device automation.
2. **Spacious Restraint:** Deliberate negative space and tactile interface textures that respect user attention and bring quiet clarity back to daily workflows.
3. **Intentional Warmth:** Technology that feels calm, gentle, and grounding — built around genuine digital wellness rather than manufactured urgency.

## ✦ Brand Guidelines (Official Brand Book)

Based on the **Studio91 Brandbook by Pomelli** (`google_labs`):

### Core Motto
> **`"Software that feels human."`**

### Logo Rules
- **Clear Space:** Always maintain at least **190 px** clear space around the logo on each side to keep it clean and legible.
- **Minimum Size:** Below **1.58 inch / 152 px width**, clarity is lost. Always honor the minimum size.
- **Color Lockup:** `Studio` in Jet Black (`#0D0D0D`) with `91` in Electric Chartreuse (`#C8FF00` / `#9DC400`).

### Color Palette

| Color Name | Hex | RGB | CMYK | HSL | Role |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Classic Linen** | `#F5F2EC` | `245, 242, 236` | `0%, 1%, 4%, 4%` | `40, 31%, 94%` | Base canvas & background |
| **Jet Black** | `#0D0D0D` | `13, 13, 13` | `0%, 0%, 0%, 95%` | `0, 0%, 5%` | Primary typography & high contrast |
| **Electric Chartreuse** | `#C8FF00` | `200, 255, 0` | `22%, 0%, 100%, 0%` | `73, 100%, 50%` | Vibrant accent & interactive focus |

### Typography
- **Primary Typeface:** `DM Serif Display` (Headings, titles, and editorial quotes)
- **Secondary Typeface:** `DM Mono` (Tags, values, metrics, and monospace accents)

## ✦ Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js:** `v18.x` or later (tested on Node `v20+` / `v26+`)
- **npm:** `v9.x` or later

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Yuvraj-ai/studio91.git
   cd studio91
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

   > **Note:** If encountering peer dependency warnings between React 19 and older third-party packages, run:
   > ```bash
   > npm install --legacy-peer-deps
   > ```

## ✦ Available Scripts

In the project root, you can run:

### `npm start`

Builds the app for production to the `build/` folder.\

### `npm test`
Launches the test runner in interactive watch mode using Jest and React Testing Library.

## ✦ Configuration & Contact Form

The contact form in [`src/App.jsx`](src/App.jsx) is powered by **EmailJS**. Credentials are configured directly in the component:

```javascript
const EMAILJS_SERVICE_ID  = "service_ozzpa1d";
const EMAILJS_TEMPLATE_ID = "template_uy9h0yi";
const EMAILJS_PUBLIC_KEY  = "Or8WawFxe2jXw-BKW";
```

To connect your own EmailJS account:
1. Register for an account at [emailjs.com](https://www.emailjs.com/).
2. Create an Email Service and an Email Template.
3. Replace the service ID, template ID, and public key in [`src/App.jsx`](src/App.jsx).
